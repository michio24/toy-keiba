# トイ競馬

かわいい馬たちが走る、3Dブラウザ競馬ゲームです。出走馬とコースを選び、ゲーム内のコインで馬券を買って、応援しながらレースを楽しめます。パソコン・スマートフォンに対応しています。

ロビーで「競馬／クラッシュ」を切り替えられます。コインは両モードで共有し、購入・換金・実際のお金を使う機能はありません。

## 起動方法

フォルダ内の `index.html` をブラウザで開くと遊べます。インストールやビルドは不要です。`lib/` は同じフォルダに置いてください。

3D描画に必要な three.js は同梱しているため、オフラインでも動作します。Google Fonts から読み込むフォントは、オフラインでは端末の標準フォントに切り替わります。

## 遊び方

1. 「今日のレース」カードまたは「コース」タブからコースを選びます。「すべて／ファンタジー／国内／海外」で絞り込めます。
2. 「出走馬」タブで応援する馬を選びます。
3. 単勝（1着）または複勝（3着以内）を選び、賭けるコインを設定します。出走ボタンの上で、選択した馬・券種・倍率・的中時の払戻を確認できます。
4. 「出走！」でレースを開始します。応援ゲージがたまったら、応援ブーストを使えます。
5. 結果画面で着順と払戻を確認し、次のレースへ進みます。

初回は遊び方ガイドを表示します。「おまかせで初レース」では、最初のコース・複勝100コインで始められます。ガイドは左上のメニューから再表示できます。スマートフォンでは「出走馬／コース／馬券」のタブで設定を切り替えます。

## 操作

### クラッシュモード

1. ロビーで「クラッシュ」を選び、馬・コース・賭け額を設定します。自動キャッシュアウトは初期状態ではOFFで、ONにすると `1.01〜100.00x` を小数2桁まで指定できます。
2. 「クラッシュ出走！」で開始します。8頭が走る間、倍率が `1.00x` から上昇します。選んだ馬が上位ほど倍率が速く伸びます。能力・スキル・応援ブーストは従来どおり走行に作用します。
3. 疾走終了前に「確定」ボタンまたは `Enter` でキャッシュアウトすると、賭け額×確定倍率を受け取れます。払戻には賭けた分を含みます。`Space` は応援、`1`〜`6` と `C` はカメラ切替です。
4. 自動設定倍率、または `100.00x` 到達で自動確定します。先にクラッシュすると払戻は0です。開始直後にクラッシュする場合もあります。
5. 結果で確定倍率・払戻・差引収支・終了時点の順位を確認し、次のラウンドを手動で開始します。

ゴールは終了条件ではなく、馬は周回コースを走り続けます。各馬が設定距離を走るごとにスタミナが全回復し、脚質の展開とスキル抽選を繰り返します。距離・順位・倍率・応援ゲージは引き継ぎ、応援効果は残り時間まで続きます。この区間は物理的な一周とは異なります。直線コース「新潟千直」は競馬モードのみで選択できます。

倍率の節目（1.10／1.25／1.50／2／3／5／10／20／50倍）では、確定の判断を迫るメッセージと効果音が入ります。1.5倍以降は倍率パネルの色・光の脈動・心拍音が段階的に強まり、未確定の利益も表示します。演出は表示倍率に連動し、隠れた終了倍率の予告ではありません。音ボタンで消音でき、端末で「動きを減らす」を設定している場合は追加の脈動を停止します。

理論RTPは96.5%です。走行とは独立した一様乱数 `0 < U < 1` からクラッシュ倍率 `C = 0.965 / U` を抽選し、`C ≤ 1` は開始直後の終了とします。固定倍率 `m > 1` に到達する確率は `0.965 / m` なので、丸め前の期待払戻は賭け額の96.5%になります。順位は `d(log倍率)/dt = (0.08 + 0.005 × (8 − 順位)) / 3` により、目標倍率までの時間を変えます。上昇速度は1位で毎秒約3.8%、8位で約2.7%（複利）です。順位や応援を楽しめるよう、当初の約1/3の速度にしています。クラッシュ確率そのものに能力や応援による補正は加えません。

手動確定は表示と同じ小数2桁に切り捨てた倍率、自動設定は指定倍率で精算します。理論RTP 96.5%。整数丸めにより実際の期待払戻はわずかに下がります。短期間の実測RTPが96.5%になる保証はありません。クラッシュでは連勝ボーナスや競馬の実績報酬は加算せず、競馬の連勝・実績も更新しません。残高100未満での無料500コイン補充は共有しますが、RTPには含めません。

非表示タブではクラッシュの進行を一時停止します。未確定で再読み込みすると、そのラウンドは払戻なしで終了します。保存が利用できる環境では、引き落とし済みの残高を復元してお知らせを表示します。

### 競馬モードの操作

| 操作 | パソコン | スマートフォン |
|---|---|---|
| 視点を動かす | マウスドラッグ | スワイプ |
| ズーム | マウスホイール | ピンチ |
| レース中のカメラ切り替え | 画面のボタン、`1`〜`6`、`C`で順送り | 画面のボタン |
| レース中の観戦対象切り替え | 順位表の馬をクリック。同じ馬を再度クリックすると先頭追尾に戻る | 順位表の馬をタップ。同じ馬を再度タップすると先頭追尾に戻る |
| 応援ブースト | 応援ボタンまたは `Space` | 応援ボタン |
| 音のオン／オフ | 音ボタンまたは `M` | 音ボタン |
| 馬図鑑を閉じる | 「ロビーへ戻る」または `Escape` | 「ロビーへ戻る」 |

観戦対象は競馬・クラッシュの両モードで全6種類のカメラに反映されます。競馬は初期状態で先頭交代に追従し、クラッシュはベットで選んだ馬を追従して開始します。順位表で馬を選ぶと順位が変わってもその馬を追い続けます。固定した観戦対象を緑色の枠で表示し、同じ馬を再度押すと選択を解除して先頭追尾に戻ります。カメラの種類を変えても対象は維持し、次のレースでは各モードの初期対象に戻ります。

観戦対象を変えても馬券・応援の対象は変わりません。特定の馬を選んでいる間は接戦時の自動ゴールカメラとスロー演出を抑えます。導入・カウントダウン・結果画面では既存の演出を優先します。

## 馬とコース

左上のメニューの「コース図鑑」では、全景の回転・平行移動に加えて「ドローン」で自由に飛行できます。入力を離すとその場で静止し、地形や建物に接触すると止まります。「全景へ戻る」で回転モードへ復帰し、`Escape`でロビーへ戻ります。

| ドローンの操作 | パソコン | スマートフォン |
|---|---|---|
| 水平移動 | `WASD` | 左側の移動パッド |
| 上昇・下降 | `E`／`Q` | 右側の▲／▼ボタン |
| 見回す | マウスドラッグ | 描画領域をスワイプ |
| 速度変更 | 画面の「低速／標準／高速」 | 同左 |

移動・見回し・上昇下降は同時に操作できます。速度の初期値は標準です。飛行中はホイール・ピンチによるズームを使わず、移動して近づきます。「回転」「移動」へ切り替えると飛行前の視点に戻り、コース変更時は全景から始まります。飛行位置は保存されません。動く装飾・空・図鑑で非表示の遠景は衝突対象に含めません。

飛行の移動・衝突・入力解除の自動テストは `node --test tests/drone.test.cjs` で実行できます。

馬ごとに脚質・能力・適性・専用スキルがあり、コースやレース展開によって走りが変わります。名馬や歴史上の馬をモチーフにした馬のほか、ファンタジーやユニークな姿の馬も登場します。

左上のメニューにある「馬図鑑」では、出走していない馬も含めて閲覧できます。馬名検索と「すべて／名馬モチーフ／歴史／その他」の絞り込みに対応し、紹介文・能力・適性・スキル・プロフィールを確認できます。3D展示では「待機／走る／スキル」を切り替え、回転やズームで姿を眺められます。「スキル」では発動条件や確率に関係なく、発光や専用の動きなど、発動中の演出を繰り返し確認できます。

コースには、ファンタジーの舞台と国内外の実在競馬場をモチーフにした舞台があります。芝・ダート、直線やカーブ、坂などの特徴をゲーム向けに表現しています。

国内8・海外4競馬場には、それぞれを象徴する建物やオブジェを配置しています。実物の特徴とおおまかな配置を参考に、全景でも見分けられる大きさにデフォルメしたトイモデルです。レース能力や当たり判定には影響しません。代表物は低画質でも表示し、花壇や噴水の細部を省略します。

競馬のオッズは、馬の能力・距離・路面適性・調子・道悪適性による簡易評価と、8回のレースシミュレーションを組み合わせて算出します。簡易評価を24回分の重みで混ぜ、少数の試行で倍率が極端に偏るのを抑えています。実際の勝率を保証するものではありません。

馬名・能力・スキル・プロフィールはゲーム用の創作です。実在の馬の走り方や競馬場の形状・高低差にもアレンジや誇張を加えており、実測値や実寸を忠実に再現したものではありません。歴史モチーフの紹介文では、史料の記述と伝承を区別しています。

## 実況・実績・結果カード

- **実況**：先頭交代、接戦、残り距離、ゴールの着差などに合わせてテキストを表示し、ブラウザの読み上げ機能で再生します。既存26コース、名馬モチーフ18頭、歴史名馬5頭、電車のマルーンライナーと、コース・馬の13組の組み合わせに、有名実況を連想させるオリジナルの専用実況215文を追加しています。導入・直線・スキル・追い上げ・勝利の場面で、条件に合う組み合わせ、馬、コースの順に専用実況を選び、それ以外は汎用実況を使います。残り距離や着差は実際の展開に合わせ、クラッシュでは最終直線や勝利の実況を出しません。音の設定は効果音と共通です。声や日本語音声の利用可否はブラウザ・OSによって異なります。
- **実績**：完走、異なる馬やコースでの完走、応援ブーストで実績と称号を獲得できます。勝敗に関係なく進捗を保存し、コイン報酬は実績ごとに一度だけ受け取れます。
- **結果カード**：応援した馬がゴールした瞬間の写真と、着順・馬名・コース・タイム・払戻をまとめたカードです。結果画面の「結果カードを保存・共有」からPNGを保存できます。写真はレース中に一度だけ撮影し、次のレースには持ち越しません。撮影できない場合は文字のみのカードになります。共有に対応したブラウザでは共有メニューを開き、それ以外では共有文のコピーまたは表示に切り替わります。

過去の名実況から短いフレーズを使った実況8種類も追加しています。既存のオリジナル実況に混ぜて選び、同じ候補群では直前と同じ文を避けます。馬名はゲーム内の名前に置き換わります。逃げのフレーズはイジゲンエスケープが後続を離して最終直線に入った場面、接戦のフレーズは僅差のゴールに限定します。セイキマツハオウには2000年有馬記念を基に、中山で残り300m以内に順位を上げた場面と、僅差で勝った場面の実況を追加しています。クラッシュではこの2種類を使いません。京都の桜のフレーズは過去の実況を紹介する導入として使い、現在の季節や三冠達成を断定しません。

## 画質と保存データ

画質は画面上部で「自動／軽量／高画質」から選べます。「自動」は画面幅760px以下で軽量になります。軽量では描画解像度を抑え、影とブルームを無効にします。

所持コイン、最後に選んだコース、実績、ガイド完了状態、画質設定などはブラウザの `localStorage` に保存します。ブラウザの保存データを削除すると初期化されます。

最後に選んだゲームモードとクラッシュのガイド完了状態も保存します。共有残高と未確定ベットは `dopa_crashAccount` にまとめて保存し、既存の残高データは初回に引き継ぎます。保存できない環境では再読み込み後の残高復元は利用できません。

ローカルファイル（`file://`）では、ブラウザによって保存が使えない場合があります。その場合は、Python が利用できる環境でこのフォルダから次のコマンドを実行し、[http://localhost:8000/](http://localhost:8000/) を開いてください。

```powershell
python -m http.server 8000
```
